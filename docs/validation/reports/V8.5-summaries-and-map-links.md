## 1. A summary opens every assessment

Each of the four assessments (IBTrACS, GHCNh, JRC flood, NEX-GDDP-CMIP6) now starts with:

| Part | Where it comes from |
| --- | --- |
| What the framework adds to the publisher's data | `adds` in the source file (written by hand, like `purpose`) |
| How it is compared | `compared` in the source file |
| Result: the values compared and how many differ; then how many stated steps are confirmed | Generated from the record |
| Two bars: steps confirmed, differing, not checked; checks confirmed and differing | Generated from the record |
| What differs, the findings, a link to the map | Generated |

The result line leads with the values themselves, because a count of steps can overstate a
difference. For JRC flood: 1,447,885,064 pixel values compared, 0 differ; 10,240,052 curves
refitted, 2,959 differ (99.97% agree); 11 of 15 steps confirmed. A note generated from the record
says that the four differing steps rest on one check per area and consist of 2,957 curves the fit
does not converge on and 2 parameters beyond the tolerance.

| Assessment | Result line |
| --- | --- |
| IBTrACS | 323,369,778 values compared one by one, 0 differ |
| GHCNh | 1,000 station-years recomputed, 0 differ |
| NEX-GDDP-CMIP6 | 15,106 cell values compared at the installed version, 0 differ |
| JRC flood | as above |

The detail (counts, tables, charts, steps, checks, comparisons) follows under "In detail".

## 2. The assessment and the map are joined

- Every table and chart of the JRC assessment that counts pixels has an "On the map" line with one
  link per area to the layer that shows the same thing (for example the misfit table to the
  "largest distance" layer in Houston). The FEMA comparisons link to their four layers; the gauge
  and Harvey comparisons to the points. 40-odd links; a test checks that each names a real layer.
- Each summary links to the source in the explorer.
- In the explorer, "Read this first" now begins with the source's assessment: its status, the
  number of findings and a link to it. A layer that shows a finding links to that finding.
